# My 90-Day DevOps Learning Plan

## 1. What is my understanding of DevOps and Cloud Engineering?

According to my understanding, DevOps is a culture and set of practices that help development and operations teams work together to deliver applications faster, more reliably, and with automation. It focuses on continuous integration, continuous delivery, monitoring, collaboration, and infrastructure as code.

Cloud Engineering involves designing, deploying, and managing infrastructure and applications on cloud platforms such as AWS. It enables scalability, security, high availability, and cost optimization for modern applications.

---

## 2. Why am I starting to learn DevOps and Cloud?

I started learning DevOps and Cloud because I want to build a long-term career in modern IT infrastructure and automation. I already have experience in Cloud Engineering, and I want to strengthen my skills in Linux, Networking, Git, Docker, Kubernetes, CI/CD, Infrastructure as Code, Monitoring, and AWS services.

My goal is to become a highly skilled DevOps Engineer who can design, automate, deploy, and manage production environments efficiently.

---

## 3. Where do I want to reach?

My target for the next 90 days is to:

* Build strong fundamentals in Linux and Networking.
* Master Git and GitHub for version control.
* Learn Docker and containerization concepts.
* Understand CI/CD using Jenkins.
* Gain practical experience with AWS services.
* Learn Infrastructure as Code using Terraform.
* Understand Kubernetes fundamentals.
* Learn monitoring tools such as Prometheus and Grafana.
* Build multiple hands-on projects and maintain them on GitHub.
* Prepare myself for DevOps Engineer opportunities and real-world production environments.

Long-term, I want to become a professional DevOps Engineer capable of handling cloud infrastructure, automation, monitoring, and CI/CD pipelines.

---

## 4. How will I stay consistent every single day?

To maintain consistency, I will:

* Study at least 2–3 hours every day.
* Spend more time on practical labs than theory.
* Complete daily tasks and assignments without skipping.
* Maintain notes and document everything I learn.
* Practice commands and tools regularly.
* Build projects and upload them to GitHub.
* Revise previous topics every weekend.
* Track my progress weekly.
* Stay disciplined and avoid long breaks in learning.
* Continuously improve through hands-on practice and real-world scenarios.

---

## Commitment Statement

For the next 90 days, I am committed to learning DevOps with discipline, consistency, and hands-on practice. My focus is not only on completing the course but also on developing the skills required to work confidently as a DevOps Engineer in real-world environments.
